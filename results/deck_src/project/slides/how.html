How it works

The LLM understands, the optimizer computes, the verifier checks

1 Forecast

LightGBM predicts tomorrow’s solar and demand

2 LLM agents

turn the sentence into exact rules

3 Optimizer

MILP finds the cheapest 96-slot plan

4 Verifier

checks physics, wishes and the answer

5 Score

replay the plan on the real weather

If a check fails: the plan goes back to the agents to be fixed (at most 3 replans). The answer is only given after it passes.

Each part does what it is good at: language for the LLM, exact maths for the solver, reliable rule checks in plain code.

This is our main idea. A forecaster predicts tomorrow. LLM agents read the request and set rules, like car leaves at 07:00 at 90 percent. A mathematical optimizer, a MILP, computes the cheapest schedule for every 15 minutes. A verifier written in plain code checks everything; if something is wrong, the plan goes back to the agents. Finally we replay the plan on the real weather of that day to score it fairly.
